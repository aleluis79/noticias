# news-aggregator-argentina

Aplicación agregadora de noticias de Argentina usando .NET 11 API y React, que obtenga noticias de Clarín, La Nación, Página/12, TN, Ámbito Financiero, El Cronista, Perfil, C5N y La Voz del Interior, y las muestre juntas con enlace al original. Debe seguir flujo SDD OpenSpec y TDD estricto.
